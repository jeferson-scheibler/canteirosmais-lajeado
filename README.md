# canteiro+

Página de apresentação do canteiro+, projeto independente de adoção de canteiros públicos em Lajeado (RS), construído com o objetivo de futuramente virar parceria com a Prefeitura de Lajeado.

## Estrutura

- `index.html` — página de apresentação (landing page), HTML/CSS/JS puros, sem dependências externas.
- `assets/` — arquivos de logo em suas variações (SVG e PNG, fundo claro e escuro).

## Como visualizar

Basta abrir `index.html` em um navegador, ou publicar a pasta em qualquer serviço de hospedagem estática (GitHub Pages, Netlify, Vercel etc.).
